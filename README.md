# 📱 K90 换面具工具箱
一套为 Redmi K90 / 澎湃OS 打造的 Android 终端工具箱，集成面具刷入、分区备份/刷入、镜像解包/打包、权限修复、云控禁用等功能，所有操作均在本地完成，无联网依赖。

**作者：MineACEx**

---

## ✨ 功能一览
| 功能模块 | 说明 |
|---------|------|
| 便捷式换面具 | 一键刷入/更新 Magisk/KernelSU 面具 |
| 高级重启菜单 | 快速进入 Recovery/Fastboot/9008 模式 |
| 分区备份/刷入 | 支持 A/B 分区一键备份与镜像刷入 |
| 镜像解包/打包 | boot/init_boot/erofs/ext4 镜像解包与重新打包 |
| 权限检查与修复 | 一键检查并修复目录文件为 777 权限 |
| 禁用 Joyse 云控 | 屏蔽小米云控，禁用数据上传与后台控制 |
| 一键清理脚本数据 | 清理临时文件、日志与缓存 |

## 🚀 使用方法
### 1. 前置准备
- 设备已 Root（推荐 Magisk/KernelSU）
- 安装支持 `bash/sh` 的终端（如 Termux、MT 管理器终端）
- 脚本目录已赋予可执行权限

### 2. 启动工具箱
1.  进入脚本目录：
    ```bash
    cd /data/换面具/data/
    ```
2.  赋予所有脚本执行权限（首次运行必做）：
    ```bash
    chmod 777 ./* bin/*
    ```
3.  启动主菜单：
    ```bash
    sh .main_start.sh
    ```

### 3. 功能使用示例
- **分区备份**：在主菜单选择对应序号，输入分区名（如 `boot`/`init_boot`），备份文件将自动保存至 `allimg/` 目录，命名格式为 `分区名_a_bk.img`/`分区名_b_bk.img`。
- **镜像解包**：在主菜单选择对应序号，输入镜像完整路径（如 `/data/换面具/data/allimg/init_boot_b_bk.img`），解包文件将自动输出至 `fkimgs/` 目录，ramdisk 会自动解压为可读文件。
- **禁用云控**：在主菜单选择对应序号，按提示确认执行，重启后生效。

本项目已在 GitHub 开源，可通过以下方式获取最新版本：

3.  解压后复制到设备 `/data/` 目录即可

## ⚠️ 注意事项
1.  **风险提示**：分区刷入、解包操作有一定风险，建议先备份所有分区再操作。
2.  **权限要求**：部分功能需要 Root 权限，未 Root 设备无法正常使用。
3.  **兼容性**：本工具箱专为 Redmi K90 澎湃OS 设计，其他机型需自行测试兼容性。
